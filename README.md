# AI画像フォレンジック

ブラウザだけで動く、ローカル画像分析のMVPです。画像をアップロードすると、Canvas ベースの前処理とヒューリスティック分析で、AI生成・編集・合成などの可能性を推定します。

## 概要

- 外部AI APIは使用しません
- 画像はブラウザ内で解析します
- WebGPU の有無を検出して表示します
- URL入力にも対応しますが、CORS の影響を受けます
- 解析結果は確定的な証拠ではなく、視覚的特徴の推定です

## アーキテクチャ

- Next.js / React / TypeScript
- クライアント側で画像を読み込み
- Canvas で画像を縮小・前処理
- ローカル画像統計から証拠を構成
- Model Score と Derived Score を分けて表示

## ローカル推論について

このMVPはブラウザ内で動く軽量な解析を優先しています。

- WebGPU は検出のみ行います
- 初回ロードや画像URL取得ではネットワーク通信が発生する場合があります
- 画像ファイルそのものは外部AI APIへ送信しません

## 使用モデル

- 現時点では外部モデルは使いません
- Canvas ベースのローカル画像解析を採用しています
- Phase 2 で WebGPU 対応の軽量モデルを追加しやすい構造です

## ブラウザ要件

- Chrome 系ブラウザ推奨
- `navigator.gpu` が使える環境では WebGPU を検出します
- URL入力は CORS により失敗する場合があります

## セットアップ

```bash
npm install
npm run dev
```

## 開発方法

```bash
npm run lint
npm run typecheck
npm run build
```

## Demo Mode

`.env.local` で `DEMO_MODE=true` を設定すると、デモ表示を有効にできます。

## Vercelへのデプロイ

- Next.js としてそのままデプロイできます
- 外部AI APIキーは不要です
- サーバー側の推論処理は使いません

## プライバシー

- 画像はブラウザ内で解析します
- 画像データベース保存は行いません
- 解析結果はローカル UI にのみ表示します

## 制限事項

- 科学的に検証されたフォレンジック判定器ではありません
- AI生成を確定するものではありません
- URL入力は CORS の制約を受けます
- 高度な物体検出モデルは未実装です

- より精密な物体検出
- 局所領域の分析強化
